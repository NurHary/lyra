# Lyra Multi Purpose C Library

Custom Multi Purpose C Library Used by KillingWhales / myself, written
in pure C with support for C99 without any dependencies except for
libc.  Lyra is mixed single header paradigm and traditional library.

# Libraries


<detail>
<summary>Macros Flag</summary>
## Main Macros Flag
- LYCONFIG="files.config": enables global configuration of lyra
- NDEBUG : No Debug / disable debug info
