Custom Multi Purpose C Library Used by KillingWhales / myself, written
in pure C with support for C99 without any dependencies except for libc

## Main Macros Flag

# Dual Mode Library

Lyra is mixed single header paradigm and traditional library.

# Coding Convention

- Function to create struct or freeing it will be written as snake_case while
  function who work around struct use camelCase
- Macros Config always have "LYC_" prefix
